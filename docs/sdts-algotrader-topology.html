SDTS / AlgoTrader — Network Topology & Data Flow

A typed-node mesh over YX: every edge is a JSON-RPC message (Protocol 0, UDP broadcast 255.255.255.255:50000, HMAC-signed). Toggle a lane in the legend; hover any node or edge for detail.

State / observability
Manager (control plane)

How it operates

  1. Market data: IBKR → ib-bridge (ib_async) → ib.tick → algos & logger.
  2. Signal: algo → signal.order → orchestrator.
  3. Order: orchestrator → ib.place_bracket_order → ib-bridge → IBKR.
  4. Fills/events: IBKR → ib.orderStatus → orchestrator → trade-tracker state machine → trade.entryFilled → logger.
  5. Control plane: ServiceManager does dependency-ordered start/stop, system.ping & health_check.
