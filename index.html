YX — secure UDP messaging protocol

Author: Scott D. Yelich · Updated: 2026-07-19 · Version: 2.1.0

YX is a secure, payload-agnostic UDP messaging protocol with a byte-identical wire format across Swift and Python. The canonical implementation is the production code promoted from the sdts trading system, where it runs AlgoTrader's service mesh — sdts now consumes yx back as a git-submodule dependency.

Overview

Packet: HMAC-SHA256(16B) + GUID(6B sender id) + payload, over UDP. No TCP, no PKI.

  • Protocol 0 — text / JSON-RPC
  • Protocol 1 v2.0 — binary: 65,535 channels, chunking, per-channel sequences
  • HMAC-SHA256 packet integrity (16-byte truncated), constant-time compare
  • Optional AES-256-GCM encryption
  • Broadcast-based peer discovery
  • Byte-identical wire format across Swift and Python

Swift-first (ADR D09)

Swift is the base implementation, consumed via SPM — this repo IS the Swift package. Libraries: Primitives, Transport, RPC, YX. Executables:

  • yxCLI — test/demo CLI (drives the live cross-language smoke test)
  • yxkey — mesh key manager (generate|set|get|list|remove; set reads stdin, never argv). Mesh HMAC keys live in the macOS Keychain (ADR D08, service org.spy.yx); resolution order: --key flag > YX_KEY env > Keychain > built-in dev key (with a loud warning). Spec: protocol/specs/architecture/key-management.md.
  • yxnode — base mesh node daemon and the canonical "how to build a service on yx" example: heartbeats presence (node.hello), answers node.info RPC, and on inbound msg.deliver writes a Unified Node Format (UNF) markdown file (YAML frontmatter + body) to ~/ai/mail/YYYY/MM/<id>.md for locally-addressed agents. Swift yxnode is production; the Python yxnode is spec-proof only.

The Python implementation (src/python/) is kept for wire-parity validation and the two Python-bound edges (ib_async, MLX). It is used in-tree / via submodule path — there is no pip/PyPI distribution.

Honest limitations

  • Best-effort UDP — the reliability/message-bus layer (ack/retry/dedup) is not built yet
  • Bonjour/mDNS not implemented (ADR D10 designs for it; broadcast only today)
  • Mesh-key distribution is manual (per-node Keychain)
  • The older line's formal 48-test interop matrix has not been re-run on v2 framing — interop is proven via the live cross-language node tests plus the unit suites

Architecture decisions

ADRs live in protocol/specs/architecture/ybs-decisions.md:

  • D08 — mesh keys live in the macOS Keychain, never in repos
  • D09 — Swift is the base implementation; Python is validation + edges
  • D10 — discovery is pluggable: UDP broadcast now, Bonjour/mDNS later

Ecosystem

yx is the transport/data-plane of the portfolio: it underpins a cross-machine agent message bus (laniakea stands nodes up and its svc tool supervises them; yxnode connects them), sibling Swift agents (murphy, agent, dagsmith, memory, mind) can message over it, and its spec discipline comes from ybs. The earlier YBS clean-room rebuild is preserved on branch archive/main-ybs-completed (tag pre-main-reconcile).
