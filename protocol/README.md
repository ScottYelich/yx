# YX Protocol Specification

This directory contains the **language-agnostic** YX protocol specification.
It describes WHAT YX is — the wire format, security model, protocol layers,
and testing requirements — independently of any implementation language.

## Purpose

Any language (Python, Swift, Rust, Go, ...) that implements YX must conform to
these specifications. The specs do not prescribe implementation details; they
prescribe observable behaviour and wire-format compatibility.
