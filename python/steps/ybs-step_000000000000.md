# Step 0: Python Build Configuration

**Version**: 0.1.0
**Step ID**: ybs-step_000000000000

## Overview

Collect all configuration parameters for building the YX Python implementation
and set up the build workspace. After this step, all subsequent steps run
autonomously with zero user interaction.

## What This Step Builds

A `builds/<build_name>/` workspace containing `BUILD_CONFIG.json`,
`BUILD_STATUS.md`, and `SESSION.md`, plus the initial directory scaffolding
for a Python project. This is the foundation all other steps build on top of.

## Step Objectives

1. Check for existing `BUILD_CONFIG.json` — skip questions if found
2. Collect: build name, Python version, whether to generate tests
3. Create `builds/<build_name>/` directory tree
4. Write `BUILD_CONFIG.json` with all collected values
5. Write `BUILD_STATUS.md` with initial progress tracking
6. Write `SESSION.md` for crash recovery
7. Point to Step 1 (`ybs-step_a1b2c3d4e5f6`)

## Prerequisites

- `yx/` project root exists
- Python 3.10+ installed and on `$PATH`
- pip available

## Configurable Values

- `{{CONFIG:build_name|string|Build directory name|python-impl}}`
- `{{CONFIG:enable_tests|boolean|Generate unit tests for each step|true}}`
- `{{CONFIG:python_version|string|Minimum Python version|3.10}}`

## Instructions

### Before Starting — Record Start Time

Record the current timestamp in ISO 8601 format: `YYYY-MM-DDTHH:MM:SSZ`
This is used for the DONE file duration calculation.

### 1. Check for Existing Configuration

```bash
test -f builds/{{CONFIG:build_name}}/BUILD_CONFIG.json && echo "EXISTS"
```

**If BUILD_CONFIG.json exists:**
- Read and display the configuration
- Skip all questions below
- Proceed directly to Step 1 (`python/steps/ybs-step_a1b2c3d4e5f6.md`)

**If BUILD_CONFIG.json does NOT exist:** continue to step 2.
