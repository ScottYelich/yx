# YX Protocol — Swift Implementation

**Status**: ✅ Complete (`canonical/swift/`)
**Protocol spec**: [`../protocol/specs/`](../protocol/specs/)

## What This Is

The Swift implementation of the YX protocol. It validates against canonical test
vectors generated by the Python reference implementation, proving cross-language
wire-format compatibility.

## Build Instructions

1. Ensure Python implementation is complete and `canonical/test-vectors/` exists
2. Start at the `yx/` project root
3. Execute Step 0: `swift/steps/ybs-step_000000000000.md`
4. Follow the step sequence in `swift/steps/STEPS_ORDER.txt`
5. Build output lands in `builds/<build_name>/`
