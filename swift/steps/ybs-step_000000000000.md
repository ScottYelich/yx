# Step 0: Swift Build Configuration

**Version**: 0.1.0
**Step ID**: ybs-step_000000000000

## Overview

Collect all configuration parameters for building the YX Swift implementation
and set up the build workspace. After this step, all subsequent steps run
autonomously with zero user interaction.

## What This Step Builds

A `builds/<build_name>/` workspace containing `BUILD_CONFIG.json`,
`BUILD_STATUS.md`, and `SESSION.md`, plus the initial directory scaffolding
for a Swift Package Manager project. This is the foundation all other steps
build on top of.

## Step Objectives

1. Check for existing `BUILD_CONFIG.json` — skip questions if found
2. Collect: build name, Swift version
3. Verify canonical artifacts exist (`canonical/test-vectors/`)
4. Create `builds/<build_name>/` directory tree
5. Write `BUILD_CONFIG.json` with all collected values
6. Write `BUILD_STATUS.md` with initial progress tracking
7. Write `SESSION.md` for crash recovery
8. Point to Step 1 (`ybs-step_a1b2c3d4e5f6`)

## Prerequisites

- Python implementation complete (`canonical/python/` exists)
- Canonical test vectors exist (`canonical/test-vectors/*.json`)
- Swift 5.9+ installed (`swift --version`)
- Swift Package Manager available

## Configurable Values

- `{{CONFIG:build_name|string|Build directory name|swift-impl}}`
- `{{CONFIG:swift_version|string|Minimum Swift version|5.9}}`

## Instructions

### Before Starting — Record Start Time

Record the current timestamp in ISO 8601 format: `YYYY-MM-DDTHH:MM:SSZ`

### 1. Verify Prerequisites

```bash

swift --version && echo "✓ Swift available" || echo "✗ Swift not found"
```

If canonical test vectors are missing, STOP and instruct the user to complete the Python build first.

